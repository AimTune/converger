# Vendored mekik/1 golden fixtures

These files are copied unchanged from
[AimTune/mekik](https://github.com/AimTune/mekik), directory `conformance/fixtures/`, at commit
`6068e4ea1e6cdcf1517ff7a41964a1bd05c53eda`.

`test/protocol/protocol_conformance_test.exs` validates every frame in each fixture's
`expectedFrames` against the Converger Protocol v1 server-frame schema
(`priv/protocol/v1/server-frame.schema.json`) and checks their `seq` numbering. This is part of
the mekik/1 compatibility promised in `docs/protocol/v1.md` (section 14) and issue #63. The
`events` (ilmek event streams) are not used by Converger.

To update, copy the files again from a newer mekik commit, update the SHA above, and run
`mix test test/protocol`. Do not edit the fixtures by hand: in mekik they are generated by the
TypeScript reference and treated as read-only goldens.
