# 2026-10-15: rolling restart with 10 000 sockets, after #198

The same run as the [first 10 000-socket rolling restart](2026-10-15-a8dd704-rolling-restart-10k.md), on the branch of
[#198](https://github.com/AimTune/converger/issues/198): the per-node admission queue for handshakes and replays
([ADR-0077](../adr/0077-admission-queue-for-reconnect-bursts.md)), one database checkout per handshake, and the harness
client reconnecting to a random other node and honouring `retryAfterMs`.

```bash
LOAD_NODES=3 LOAD_SCENARIOS=rolling_restart LOAD_CONVERSATIONS=1000 LOAD_SUBSCRIBERS=10 LOAD_RATE=0.1 \
  LOAD_RESTART_CONNECT_RATE=100 LOAD_RESTART_DELAY_S=130 LOAD_WARMUP_S=0 load/run.sh
```

Same developer machine (Ryzen 5 7600X, 12 vCPUs and 31 GiB for Docker Desktop), nothing else running in Docker.

## Before and after

| Metric | Before ([a8dd704](2026-10-15-a8dd704-rolling-restart-10k.md)) | After |
| --- | --- | --- |
| Sockets verified, lost acked messages | 10 000, **0** | 10 000, **0** |
| Client reconnect p50 / p95 / max | 30.0 s / **93.6 s** / 175.5 s | 0.9 s / **6.0 s** / 7.4 s |
| Reconnects | 12 420 | 15 819 |
| REST → WS p50 / p95 / max during the run | 746 ms / 2.3 s / 12.3 s | 254 ms / 545 ms / 3.6 s |
| REST send retries | 42 307 | 679 |
| `replay_unavailable` answers | 3 449 | 0 |
| DB pool queue wait, max | 1.7 s | 87 ms |
| Nodes ready again after restart | 27–38 s | 21–31 s |
| Messages acked | 21 250 | 28 001 |

The 30 s goal of [ADR-0027](../adr/0027-websocket-limits-backpressure-and-draining.md) is met with room to spare.

Two caveats when comparing:

- **Part of the gain is the harness.** Before, a dropped client always reconnected to the next node, so every socket
  of a drained node landed on one survivor, which was restarted next. Now it picks a random other node, the way a load
  balancer spreads clients. A real deployment behind a load balancer never had the old pile-up.
- More reconnects in the after run is expected: with the old backoff, many clients were still waiting when the run
  ended.
